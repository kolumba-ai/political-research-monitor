4 · Design

Four systems, each with one job

System A

Knowledge graph

Countries, government bodies, offices and verified officeholders.

Neo4j

Built: Mexico, Pakistan

System B

Social claims

Posts by and about each politician, scored for relevance.

Postgres

Built: phases 0–1

System C

Evidence graph

Documents mapped to claims as supporting, contradicting or context.

Postgres + past.dev

Built: M0–M1

System D

Polling

Polled versus social sentiment for each claim, with a stopping rule.

Neon + Modal

Designed, tests planned

Each system trusts only the one before it: B never creates a politician, C never keeps a quote it can’t find on the page, and D never stops before every population group has 5 answers.

Design documents for Systems B, C and D are in the repository, written for Devin to build from

The design is four systems in a chain. A is the knowledge graph of who holds which office, built for Mexico and Pakistan. B captures social posts by and about each politician. C finds evidence and maps it to each claim. D polls a sample about each claim and compares polled sentiment with social sentiment. A, B and C are built to the stages shown; D is fully designed with a test plan and ready to build.
