5 · The tools

What each tool does in the pipeline

Research

Exa

Finds and re-fetches the pages behind every fact; monitors flag changes.

Social

Oriane

Captures posts on TikTok, Instagram, YouTube, X and Facebook.

Reasoning

Claude

Plans searches, extracts claims, judges stance, writes poll questions.

Memory

past.dev

Keeps each politician’s claims and evidence for agents to recall.

Data

Neo4j

The graph of countries, offices and officeholders.

Data

Neon

Postgres and pgvector: claims, respondents, sampling state.

Compute

Modal

Runs every agent; the polling fleet fans out in parallel.

Channels

Vapi, WhatsApp

Voice and chat polling of real respondents, phase 2.

Build

Claude Code

Research, design documents, pilots and the test plan.

Build

Devin

Builds each system from its design document.

Blue: finding and judging · grey: storing · orange: running and building

Exa does the research: it finds pages and re-fetches them so every fact is checked against the text. Oriane captures social posts. Claude reasons over them. past.dev is the memory layer for evidence. Neo4j and Neon store the graph and the polling data. Modal runs the agents. Vapi and WhatsApp will carry real polls. Claude Code wrote the research and designs, and Devin builds from them.
